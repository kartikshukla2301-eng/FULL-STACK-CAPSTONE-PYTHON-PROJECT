# TaskFlow Pro - End User Manual

Welcome to TaskFlow Pro! This guide walks you through managing project boards, drag-and-drop Kanban, and analyzing team performance.

---

## 🚀 1. Authentication & Workspace Selection
1. Open [http://localhost:3000](http://localhost:3000).
2. Login with demo credentials (`demo@taskflow.com` / `demo123!`).
3. Select your active project workspace from the **Projects** tab.

---

## 📋 2. Managing Tasks on the Kanban Board
- **Creating Tasks**: Click **Add Task**, specify title, priority, and estimated hours.
- **Updating Status**: Select status dropdown (To Do -> In Progress -> In Review -> Completed) to trigger instant real-time synchronization across all team members.
- **Exporting Reports**: Click **Export CSV** to stream structured project task data for Excel/BI tools.

---

## 📊 3. Analytics & Burndown Insights
- Navigate to **Analytics** to view real-time burndown charts and velocity metrics across historical sprints.
